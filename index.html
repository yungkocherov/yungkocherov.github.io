Mushroom Map
Интерактивная грибная карта Ленинградской области. 913K лесных полигонов из ФГИС ЛК раскрашены по породе, бонитету и возрасту. Клик по лесу — попап с теоретическими видами грибов (из справочника «вид ↔ тип леса») и эмпирическими наблюдениями из VK. Поиск по виду гриба и по месту, сезонный фильтр, наложение водоохранных зон и ООПТ.

Mushroom Forecast
ML-пайплайн для прогнозирования грибного сезона. Собирает посты из VK-групп по 5 городам за 8 лет, классифицирует фото, нормализует количество находок по аудитории и дню недели. 261 погодная фича: температурные лаги, накопленные осадки, влажность почвы (ERA5), GDD, паттерн «дождь→тепло», климатические аномалии. 5 панельных LightGBM-моделей по группам видов (болетовые, лисичковые, опята, весенние).

Brand Events Finder
Веб-сервис для поиска значимых событий по брендам: ребрендинги, скандалы, уход с рынка, новые продукты. AI-агент фильтрует результаты DuckDuckGo, извлекает даты публикаций, оценивает влияние на бизнес (1-5) и тональность. 4 LLM-провайдера (Mistral, OpenAI, Claude, Gemini). Экспорт в CSV с dummy-переменными по дням/неделям/месяцам — готовый датасет для моделей. 101 тест.
